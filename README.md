# SuperJet Notification Monitor

نسخة اختبار أولى لقراءة إشعارات Android فقط.

## الوظائف
- NotificationListenerService
- عرض اسم التطبيق والحزمة والعنوان والنص والوقت
- حفظ آخر 300 إشعار محليًا
- لا يوجد إرسال للإنترنت
- لا يوجد ربط ببايثون في هذه النسخة

## التشغيل
1. افتح المشروع في Android Studio.
2. انتظر Gradle Sync.
3. Build > Build APK(s).
4. ثبت APK على الهاتف.
5. افتح التطبيق.
6. اضغط "فتح صلاحية قراءة الإشعارات".
7. فعّل SuperJet Payment Monitor.
8. أرسل/استقبل إشعارًا تجريبيًا.
9. ارجع للتطبيق وستجد الإشعار في السجل.

ملاحظة: Android لا يسمح بقراءة الإشعارات إلا بعد منح Notification Access للمستخدم.
